# 时间账本 v1.2

三页，每页只管一件事：

- **我的一天**：现在该干什么。时间轴 + ▶ 开始 45 分钟（⑦ 30 分钟）+ 打勾。只用来执行，这一页不能改。
- **定量**：每块干多少。每个单位一张卡：保底量、范围（没定死时写，显示“试行中”）、熟练度、第一步、今天的数据（Anki、听力/阅读正确率、要点进度等）。
  - 第一步随时改；保底量 / 范围 / 熟练度改的时候写一句原因，自动记进“调整记录”。最好留到周日改。
- **复盘**：想到哪说到哪，可不写。“📋 复制今晚复盘”把完成情况、卡点、定量数据和你的想法打包，粘贴给 AI 讨论；聊完把结论贴回来。以前的复盘按日期列出，方便以后找规律。底部是想法冷却区（48 小时）。

方法库、旧进度页已从导航移除，数据仍保留在浏览器里。

纯 HTML/CSS/JS，数据存在浏览器 localStorage（键名不变，升级不丢数据），可导出 / 导入 JSON 备份。
默认作息和定量在 `data.js`；网页上“定量”页的修改优先。
