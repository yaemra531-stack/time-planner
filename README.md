# 时间账本

把每日固定作息、两本书的方法卡和每日数据放在一个页面里。

- **我的一天**：全天时间轴，自动标出“现在该做什么”和剩余时间；7 个 45 分钟单位可以打勾。
- **方法库**：顾家北写作、慎小嶷口语，每节一张方法卡（核心观点、具体方法、怎么练、每天的固定量）。
- **进度**：每天记录听力、阅读正确率和 Anki 新词，显示连续打卡、词汇进度和正确率趋势。

纯 HTML/CSS/JS，数据存在浏览器 localStorage，可导出或导入 JSON 备份。直接打开 `index.html` 即可使用，也可以推到 GitHub Pages。

改作息、方法卡章节、关联系统链接：编辑 `data.js`。
